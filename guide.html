01 / Find your entry point

Start with one problem you can finish.

Choose a difficulty that feels slightly uncomfortable, not impossible. Read the statement twice, write down the input and output shape, then test your idea on the sample before opening the editor.

01 Scan the constraints. They usually reveal the intended complexity.
02 Plan before coding. Name the state, transitions, or data structure first.
03 Make a tiny test. Include the smallest and the strangest case you can imagine.
02 / Submit cleanly

Keep the first submission small.

Select a supported language, paste only the solution you need, and submit. Astra runs your program against hidden tests and reports the first useful signal — the verdict.

solution.cpp C++17 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}

This example reads two integers and prints their sum. Replace the logic with your own solution, then use Submit when the program is ready.

03 / Learn from feedback

Every verdict is a clue.

Use the result to narrow the next action instead of rewriting everything at once.

AC / Accepted

Your output passed every test. Review the idea once before moving on.

WA / Wrong answer

Find a counterexample. Check boundaries, duplicates, and integer overflow.

TLE / Time limit

Estimate the complexity again and look for repeated work inside loops.

RE / Runtime error

Inspect indexes, empty input, division by zero, and memory usage.

04 / Build the habit

One solved problem is a useful start.

After each solve, write one sentence about the key idea. Return to it later, join a contest, and let your rating reflect the practice you are building.
